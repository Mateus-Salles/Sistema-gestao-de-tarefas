## Descrição

Aplicação web para a agência de marketing Forge Growth, voltada ao controle dos projetos
internos de lançamento e à gestão financeira de recebimentos e pagamentos.

O sistema centraliza clientes, projetos, tarefas, contratos, parcelas a receber, contas a
pagar e o histórico de cobrança — informações hoje dispersas em planilhas sem padrão, o que
faz com que prazos só sejam percebidos depois de vencidos.
